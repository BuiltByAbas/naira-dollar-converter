# Naira to Dollar Converter

A simple web application that converts Nigerian naira (NGN) to US dollars (USD) using an example exchange rate.

## Features

- Enter an amount in naira.
- Convert naira to dollars.
- Display the result to two decimal places.
- Validate empty and negative inputs.
- Use a simple, responsive interface.

## How to Run It

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter an amount and click "Convert to USD".

No additional packages are required.
